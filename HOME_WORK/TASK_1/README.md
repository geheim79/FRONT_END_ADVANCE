Создание простого компонента 
○ Описание: Создайте функциональный компонент WelcomeMessage, 
который принимает пропс username и отображает приветственное 
сообщение. 
○ Пример вывода: "Добро пожаловать, [username]!" 
○ Требования: 
■ Используйте JSX. 
■ Передайте пропс username при вызове компонента. 
○ Подсказка: Создайте компонент и используйте его в ReactDOM.render.
