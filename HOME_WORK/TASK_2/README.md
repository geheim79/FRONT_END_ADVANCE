Список элементов 
○ Описание: Создайте компонент ItemList, который принимает массив 
строк через пропсы и отображает их в виде ненумерованного списка 
(<ul>). 
Пример вывода: 
 text 
СвернутьПеренос 
Копировать 
- Яблоко 
- Банан 
○ - Апельсин 
 
○ Требования: 
■ Используйте метод map для рендеринга списка. 
■ Добавьте атрибут key для каждого элемента списка. 
○ Подсказка: Передайте массив через пропс, например, items={["Яблоко", 
"Банан", "Апельсин"]}.
